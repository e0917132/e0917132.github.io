# Week 2-3. 컬렉션, 모듈

## 1. 15강 컬렉션 타입 기본

#### 1. 컬렉션 (Collection)

- 여러 값을 하나의 이름으로 묶어서 관리하는 자료형(저장소)

#### 2. 한눈에 비교

| 종류 | 기호 | 생성 함수 | 순서 | 변경 | 중복 |
| --- | --- | --- | --- | --- | --- |
| 리스트 | [ ] | `list()` | O | O | O |
| 튜플 | ( ) | `tuple()` | O | X | O |
| 세트(집합) | { } | `set()` | X | O | X |
| 딕셔너리 | {키:값} | `dict()` | X | O | X |

#### 3. 컬렉션 설명

1. 리스트(List)
    - 순서(index)가 있고 추가, 수정, 삭제 가능.
    - 저장하려고 하는 값들의 자료형이 달라도 한 리스트에 저장 가능
    - 대괄호로 생성 or `list()` 함수 사용
    
    ```python
    # 예시
    mix = ["사과", 3, 1.5, True]
    print(type(mix[0]), type(mix[1]), type(mix[2]), type(mix[3]))
    ```
    

1. 튜플(Tuple)
    - 순서(index)가 있고 변경 불가능.
    - 소괄호로 생성 or `tuple()` 함수 사용
    
    ```python
    fruits = ("사과", "배", "단감", "포도")
    ```
    

1. 세트(Set)
    - 순서 없고 변경 가능. 중복값 저장 안됨.
    - 중괄호로 생성 or `set()`함수 사용.
    - 수학의 집합과 동일한 개념
    
    ```python
    flower = {"장미", "안개꽃", "작약", "국화"}
    ```
    

1. 딕셔너리(Dictionary)
    - 순서 없고 중복 저장 안됨.
    - {키:값}의 형태로 키와 값을 쌍으로 가진 데이터 구조
    - 중괄호 생성 or `dict()` 함수 사용
    
    ```python
    score = {
    	"국어" : 90, 
    	"수학" : 100,
    	"영어" : 87
    }
    ```
    

## 2. 16강 컬렉션 타입 심화

#### 1. 컬렉션 간 차이점

- 인덱스 유무 : 세트는 인덱스(순서) 없음
나머지는 문자열처럼 인덱싱·슬라이싱 가능
- 변경 가능 여부 : 튜플만 변경 불가
- 중복 가능 여부 : 세트는 중복 불가, 딕셔너리는 키 중복 불가

#### 2. 컬렉션 내장 함수

1. 리스트 함수
    
    
    | 함수 | 기능 | 예시 
    (`a = [3, 1, 2]`로 시작) | 결과 |
    | --- | --- | --- | --- |
    | `append(값)` | 끝에 항목 1개 추가 | `a.append(5)` | `[3, 1, 2, 5]` |
    | `extend(리스트)` | 리스트 이어 붙이기 | `a.extend([7, 8])` | `[3, 1, 2, 7, 8]` |
    | `insert(인덱스, 값)` | 원하는 위치에 추가 | `a.insert(0, 9)` | `[9, 3, 1, 2]` |
    | `remove(값)` | 해당 **값** 삭제 (처음 나오는 1개) | `a.remove(1)` | `[3, 2]` |
    | `pop()` / `pop(인덱스)` | 꺼내서 반환 후 삭제 (생략하면 마지막) | `x = a.pop()` | x = `2`, 
    a = `[3, 1]` |
    | `index(값)` | 값의 인덱스 반환 | `a.index(2)` | `2` |
    | `값 in 리스트` | 포함 여부 확인 | `1 in a` | `True` |
    | `sort()` | 리스트 자체를 오름차순 정렬 | `a.sort()` | `[1, 2, 3]` |

1. 딕셔너리 함수
    
    
    | 함수 | 기능 | 예시 
    (`d = {"국어": 90, "수학": 100}`) | 결과 |
    | --- | --- | --- | --- |
    | `keys()` | 키만 반환 | `d.keys()` | `dict_keys(['국어', '수학'])` |
    | `values()` | 값만 반환 | `d.values()` | `dict_values([90, 100])` |
    | `items()` | (키, 값) 튜플 반환 | `d.items()` | `dict_items([('국어', 90), ('수학', 100)])` |
    | `update(딕셔너리)` | 병합 (겹치는 키는 새 값으로 덮어씀) | `d.update({"수학": 80, "영어": 70})` | `{'국어': 90, '수학': 80, '영어': 70}` |
    | `del 딕셔너리[키]` | 해당 키 삭제 | `del d["국어"]` | `{'수학': 100}` |
    | `clear()` | 전부 비우기 | `d.clear()` | `{}` |
    | `키 in 딕셔너리` | **키** 존재 여부 확인 | `"국어" in d` | `True` |

1. 튜플 함수
    
    : 변경할 수 없는 자료형이라서 내용을 바꾸는 함수는 없고, 조회하는 함수만 있음
    
    | 함수 | 기능 |
    | --- | --- |
    | `count(값)` | 값이 몇 개 있는지 세기 |
    | `index(값)` | 값의 인덱스 반환 |
2. 세트 함수
    
    : 수학의 집합과 같아서 추가/삭제/집합연산 함수가 있음.
    
    | 함수 | 기능 |
    | --- | --- |
    | `add(값)` | 항목 1개 추가 |
    | `update(리스트 등)` | 여러 항목 추가 |
    | `remove(값)` | 삭제 (값이 없으면 **에러**) |
    | `discard(값)` | 삭제 (값이 없어도 에러 X) |
    | `clear()` | 모두 비우기 |
    | `union()` / `|` | 합집합 |
    | `intersection()` / `&` | 교집합 |
    | `difference()` / `-` | 차집합 |

## 3.  17강 모듈

#### 1. 모듈(module)이란?

- 자주 쓰는 함수를 별도 .py 파일에 모아 둔 것 (함수의 집합)
- 다른 프로그램에서 재사용 (복사·붙여넣기 대신)
- 모듈명 = .py 파일 이름 (예: [Func.py](http://func.py/) → 모듈명 Func)

#### 2. 모듈 불러오기

1. `import 모듈명` → 모듈명.함수명() 으로 호출
2. `from 모듈명 import 함수명` → 함수명() 만으로 호출
3. `from 모듈명 import *` → 모든 함수 불러오기
4. `import 모듈명 as 별명` → 별명.함수명() (alias)

**모듈 만들고 사용하기**

### **1단계: 모듈 파일 만들기**

`mycalc.py`라는 파일을 만들고 함수를 넣는다.

```python
# mycalc.py
PI=3.14

defadd(a,b):
	return a+ b

defcircle_area(r):
	return PI* r**2

defgrade(score):
	if score>=90:
		return"A"
	elif score>=80:
		return"B"
	else:
		return"C"
```

### **2단계: 다른 파일에서 불러오기**

**모듈 파일과 같은 폴더**에 있는 파일(.py나 .ipynb)에서 불러온다.

```python
# ① import 모듈명 → 모듈명.함수명()
import mycalc
print(mycalc.add(3,5))             # 8
print(mycalc.circle_area(2))       # 12.56
print(mycalc.PI)                   # 3.14 (변수도 불러올 수 있음)

# ② from 모듈명 import 함수명 → 함수명()만
from mycalcimport import add, grade
print(add(10,20))                  # 30
print(grade(85))                   # B

# ③ from 모듈명 import * → 모든 함수
from mycalcimport import *
print(circle_area(1))              # 3.14

# ④ import 모듈명 as 별명
import mycalcas as mc
print(mc.grade(95))# A
```

### ‼️ 주피터 노트북에서 쓸 때 팁

- **파일 만들기**: 노트북 셀 맨 위에 `%%writefile mycalc.py`라고 쓰고 실행하면, 그 셀의 코드가 파일로 저장된다.
    
    ```python
    %%writefile mycalc.py
    def add(a, b):
        return a + b
    ```
    
- **모듈을 고친 뒤에는 커널을 재시작해야 한다.** 한 번 import한 모듈은 다시 import해도 새로 읽지 않는다. 메뉴에서 Kernel → Restart
- **파일 이름 주의**: `math.py`, `random.py`처럼 파이썬에 이미 있는 모듈 이름은 피할 것. 진짜 모듈 대신 내가 만든 파일이 불려 와서 에러가 날 수 있다.
