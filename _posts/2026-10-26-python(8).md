## **1. 모듈이란?**

**모듈(module)** 은 필요할 때 꺼내 쓸 수 있도록 **함수(와 변수, 클래스)를 모아 둔 `.py` 파일**이다.

- 만들어 둔 함수를 다른 프로그램에서 쓰고 싶을 때, **복사·붙여넣기는 좋은 방법이 아니다.** 원본을 고치면 복사한 곳을 전부 찾아 고쳐야 하기 때문이다.
- 자주 쓰는 함수를 별도 `.py` 파일로 모아 두고 불러 쓰면 된다.
- **모듈 이름 = `.py` 파일 이름** (`mymath.py` → `import mymath`)
- 파일 이름은 자유지만, 기능을 알 수 있게 짓는다.

### **➕ 모듈 · 패키지 · 라이브러리**

| **용어** | **의미** | **예** |
| --- | --- | --- |
| **모듈** | `.py` 파일 하나 | `math`, `random`, 내가 만든 `mymath.py` |
| **패키지** | 모듈을 모아 둔 **폴더** | `matplotlib` (안에 `pyplot` 모듈이 있음) |
| **라이브러리** | 모듈과 패키지의 묶음을 넓게 부르는 말 | 표준 라이브러리, numpy, pandas |

```
라이브러리 (matplotlib)
 └─ 패키지 (matplotlib/ 폴더)
     ├─ 모듈 pyplot.py   ─▶ 함수 plot(), show(), title() ...
     └─ 모듈 colors.py
```

`import matplotlib.pyplot as plt` = "matplotlib 패키지 안의 pyplot 모듈을 plt라는 이름으로 불러온다"

### **➕ 표준 모듈 vs 외부 모듈**

| **구분** | **설치** | **예** |
| --- | --- | --- |
| **표준 모듈** (내장) | 파이썬과 함께 설치됨. 바로 `import` | `math`, `random`, `datetime`, `json`, `collections` |
| **외부 모듈** (서드파티) | `pip install 이름`으로 설치 필요 | `numpy`, `pandas`, `matplotlib`, `requests` |

## **2. 모듈 불러오기 4가지 방법**

| **#** | **방법** | **사용법** | **특징** |
| --- | --- | --- | --- |
| 1 | `import 모듈명` | `math.sqrt(4)` | 모듈 전체를 불러옴. **`모듈명.함수명()`** 으로 호출 |
| 2 | `from 모듈명 import 함수명` | `sqrt(4)` | 특정 함수만 불러옴. 모듈명 **생략** 가능 |
| 3 | `from 모듈명 import *` | `sqrt(4)`, `pi` | 모듈의 모든 함수를 모듈명 없이 사용 |
| 4 | `import 모듈명 as 별명` | `m.sqrt(4)` | 별명(alias) 지정. 긴 이름을 줄일 때 |

```
# 1. import 모듈명
import math
print(math.cos(100))          # 0.8623188722876839

# 2. from 모듈명 import 함수명
from mathimport cos
print(cos(100))               # 0.8623188722876839

# 3. from 모듈명 import *
from mathimport *
print(pi, sqrt(9))            # 3.141592653589793 3.0

# 4. import 모듈명 as 별명
import mathas m
print(m.exp(3))               # 20.085536923187668
print(m.pi)                   # 3.141592653589793
```

```
# 여러 개를 한 번에
from mathimport sqrt, pi, floor
from mathimport sqrtas root# 함수에도 별명 가능
```

### **관례적으로 쓰는 별명**

| **모듈** | **관례** |
| --- | --- |
| numpy | `import numpy as np` |
| pandas | `import pandas as pd` |
| matplotlib.pyplot | `import matplotlib.pyplot as plt` |
| datetime | `import datetime as dt` 또는 `from datetime import datetime` |

다른 사람의 코드에 `np`, `pd`, `plt`가 나오면 별다른 설명 없이도 numpy, pandas, pyplot이라고 이해하면 된다.

> ⚠️ **`from 모듈 import *`는 되도록 피하자.** 어떤 이름이 어디서 왔는지 알 수 없고, 내가 만든 변수나 다른 모듈의 함수와 **이름이 겹치면 나중 것이 덮어쓴다.**
> 
> 
> ```python
> pi= "파이 가게"
> from mathimport *
> print(pi)       # 3.141592653589793  ← 내가 만든 pi가 사라짐
> ```

## **3. ➕ 내가 만든 모듈과 `__name__`**

### **모듈 만들기**

같은 폴더에 `mymath.py` 파일을 만든다.

```python
# mymath.py
PI= 3.14

def add(a, b):
    return a+ b

def circle_area(r):
    return PI* r** 2
```

다른 파일에서 불러 쓴다.

```python
# main.py (mymath.py와 같은 폴더)
import mymath

print(mymath.add(2, 3))          # 5
print(mymath.circle_area(10))    # 314.0
print(mymath.PI)                 # 3.14  ← 변수도 불러올 수 있음
```

### **`if __name__ == "__main__":`의 의미**

```python
# mymath.py
def add(a, b):
    return a+ b

if __name__== "__main__":
    # 이 파일을 직접 실행할 때만 동작 (테스트용 코드)
    print(add(2, 3))
```

| **실행 방법** | **`__name__`의 값** | **아래 코드 실행** |
| --- | --- | --- |
| `python mymath.py`로 **직접 실행** | `"__main__"` | O |
| 다른 파일에서 `import mymath` | `"mymath"` (모듈 이름) | **X** |

이 장치가 없으면 `import`하는 순간 테스트용 `print`까지 실행되어 버린다.

### **⚠️ 파일 이름을 표준 모듈과 같게 지으면 안 된다**

파이썬은 `import` 할 때 **현재 폴더를 먼저** 찾는다.

```
import random
   │
   ▼
현재 폴더에 random.py가 있나?
   ├─ 있음 ─▶ 내가 만든 random.py를 불러옴 → random.randint 없음 → AttributeError
   └─ 없음 ─▶ 표준 라이브러리 random 모듈을 불러옴 (정상)
```

연습 파일 이름을 `random.py`, `math.py`, `turtle.py`, `json.py`처럼 지으면 표준 모듈 대신 **내 파일**이 불러와져서 `AttributeError: module 'random' has no attribute 'randint'` 같은 에러가 난다. 연습 파일은 `random_test.py`처럼 다른 이름으로 짓자.

> 💡 Python 3.13부터는 에러 메시지 뒤에 `(consider renaming '.../random.py' since it has the same name as the standard library module named 'random' ...)`처럼 **파일 이름을 바꾸라는 안내**가 붙는다. 이 문구가 보이면 내 파일 이름부터 확인하자.
>

### **4-2. random — 난수**

```python
import random
```

| **함수** | **설명** | **범위/특징** | **예시** |
| --- | --- | --- | --- |
| `random.random()` | 0 이상 1 **미만** 실수 | `0.0 <= x < 1.0` | `0.7415504997598329` |
| `random.uniform(a, b)` | a ~ b 사이 실수 |  | `random.uniform(1, 2)` |
| `random.randint(a, b)` | a ~ b 사이 정수 | **b 포함** ⭐ | `random.randint(1, 6)` → 주사위 |
| `random.randrange(a, b, step)` | `range(a, b)` 중 하나 | **b 미포함** ⭐ | `random.randrange(0, 10, 2)` → 짝수 |
| `random.choice(seq)` | 하나 뽑기 |  | `random.choice(['가위', '바위', '보'])` |
| `random.choices(seq, k=n)` | n개 뽑기 (**중복 허용**) | 리스트 반환 | `random.choices([1, 2], k=5)` |
| `random.sample(seq, n)` | n개 뽑기 (**중복 없음**) | 리스트 반환 | `random.sample(range(1, 46), 6)` → 로또 |
| `random.shuffle(list)` | 리스트 **원본**을 섞음 | **`None` 반환** ⭐ | `random.shuffle(cards)` |
| `random.seed(n)` | 난수 시작값 고정 | 같은 seed → 같은 결과 | `random.seed(42)` |

**강의 예제: 1~10 사이 난수 10개**

```python
import random

random_number_list= []
for iin range(10):
    random_number_list.append(random.randint(1, 10))

print(random_number_list)   # 예: [4, 2, 8, 10, 2, 8, 1, 8, 1, 5] (실행마다 다름)
```

**➕ 응용: 로또 번호, 가위바위보**

```python
import random

lotto= sorted(random.sample(range(1, 46), 6))   
# 1~45 중 중복 없이 6개
print(lotto)                                     
# 예: [2, 7, 15, 18, 21, 38]

me= random.choice(['가위', '바위', '보'])
print(me)            # 예: 바위
```

> 💡 **`random.seed()`** — 컴퓨터의 난수는 시작값(seed)으로부터 계산되는 "가짜 난수"다. seed를 고정하면 매번 같은 결과가 나와서, 실험 결과를 재현하거나 채점할 때 쓴다.
> 
> 
> ```python
> random.seed(42)
> print(random.randint(1, 10))   # 2
> random.seed(42)
> print(random.randint(1, 10))   # 2  ← 다시 seed(42)를 하면 같은 값
> ```
> 

### **4-3. numpy — 배열과 수치 계산**

배열과 행렬을 기본으로 **다차원 수학 연산**을 하는 가장 기본적인 라이브러리다. pandas, matplotlib, 머신러닝 라이브러리가 모두 numpy를 바탕으로 만들어졌다.

```python
import numpyas np

a= np.array([1, 2, 3])
print(a)              # [1 2 3]   ← 쉼표 없이 출력됨
print(type(a))        # <class 'numpy.ndarray'>
print(a.dtype, a.shape)   # int64 (3,)
```

#### **리스트와 가장 큰 차이: 연산이 원소별로 된다 ⭐**

```python
a= np.array([1, 2, 3])
print(a* 2)           # [2 4 6]          ← 각 원소에 2를 곱함
print(a+ a)           # [2 4 6]          ← 같은 위치끼리 더함

b= [1, 2, 3]
print(b* 2)           # [1, 2, 3, 1, 2, 3]   ← 리스트는 반복
print(b+ b)           # [1, 2, 3, 1, 2, 3]   ← 리스트는 이어 붙이기
```

| **구분** | **리스트 `list`** | **numpy 배열 `ndarray`** |
| --- | --- | --- |
| `* 2` | 2번 반복 | 각 원소 × 2 |
| `+` | 이어 붙이기 | 같은 위치끼리 덧셈 |
| 자료형 | 섞어서 저장 가능 | **한 가지로 통일** (`[1, 2.5]` → 모두 float) |
| 속도 | 느림 | 대량 계산에서 매우 빠름 |

#### **자주 쓰는 기능**

| **기능** | **코드** | **결과** |
| --- | --- | --- |
| 연속 숫자 | `np.arange(0, 10, 2)` | `[0 2 4 6 8]` |
| 0으로 채운 배열 | `np.zeros(3)` | `[0. 0. 0.]` |
| 1로 채운 배열 | `np.ones((2, 2))` | 2×2 배열 |
| 균등 분할 | `np.linspace(0, 1, 5)` | `[0. 0.25 0.5 0.75 1.]` |
| 모양 바꾸기 | `np.arange(6).reshape(2, 3)` | `[[0 1 2] [3 4 5]]` |
| 합계 / 평균 / 최댓값 | `a.sum()`, `a.mean()`, `a.max()` | `6`, `2.0`, `3` |
| 최댓값의 위치 | `a.argmax()` | `2` |
| 조건으로 고르기 | `a[a > 1]` | `[2 3]` |
| 원소별 제곱근 | `np.sqrt(a)` | `[1. 1.41421356 1.73205081]` |

```python
m= np.array([[1, 2, 3],
              [4, 5, 6]])
print(m.shape)          # (2, 3)  ← 2행 3열
print(m[1, 2])          # 6       ← 1행 2열
print(m[:, 1])          # [2 5]   ← 모든 행의 1열
print(m.sum(axis=0))    # [5 7 9] ← 세로(열)끼리 합
print(m.sum(axis=1))    # [ 6 15] ← 가로(행)끼리 합
```

### **4-4. pandas — 표 데이터 분석**

엑셀 표처럼 **행과 열로 된 데이터**를 다루는 라이브러리다.

| **자료구조** | **의미** |
| --- | --- |
| `Series` | 1차원 (이름표가 붙은 한 줄 데이터, 표의 **열 하나**) |
| `DataFrame` | 2차원 (**표 전체**) |

**강의 예제: 딕셔너리로 DataFrame 만들기**

```python
import pandasas pd

data= {
    'name': ['James', 'Jenny', 'Chris', 'Lisa'],
    'math': [70, 80, 20, 100],
    'english': [60, 70, 80, 90],
    'music': [100, 90, 90, 50]
}
df= pd.DataFrame(data)
print(df)
```

```python
    name  math  english  music
0  James    70       60    100
1  Jenny    80       70     90
2  Chris    20       80     90
3   Lisa   100       90     50
```

딕셔너리의 **키가 열 이름**, 값 리스트가 각 열의 데이터가 되고, 왼쪽의 0, 1, 2, 3은 자동으로 붙는 **인덱스**(행 번호)다.

#### **➕ 자주 쓰는 기능**

```python
print(df.shape)              # (4, 4)  ← 4행 4열
print(df['math'].mean())     # 67.5    ← math 열 평균
print(df['math'].max())      # 100

# 조건으로 행 고르기: 수학 70점 이상
print(df[df['math'] >= 70])
```

```python
    name  math  english  music
0  James    70       60    100
1  Jenny    80       70     90
3   Lisa   100       90     50
```

```python
# 새 열 추가: 총점
df['total'] = df['math'] + df['english'] + df['music']

# 총점 높은 순으로 정렬해서 이름과 총점만 보기
print(df.sort_values('total', ascending=False)[['name', 'total']])
```

```python
    name  total
1  Jenny    240
3   Lisa    240
0  James    230
2  Chris    190
```

| **기능** | **코드** | **설명** |
| --- | --- | --- |
| 앞부분 보기 | `df.head(2)` | 처음 2행 (기본 5행) |
| 열 선택 | `df['math']`, `df[['name', 'math']]` | 하나는 Series, 여러 개(리스트)는 DataFrame |
| 이름으로 선택 | `df.loc[1, 'name']` | 인덱스 1, 열 'name' → `'Jenny'` |
| 위치로 선택 | `df.iloc[0, 1]` | 0번째 행, 1번째 열 → `70` |
| 요약 통계 | `df.describe()` | 개수, 평균, 표준편차, 최솟값, 최댓값 등 |
| 정렬 | `df.sort_values('열', ascending=False)` | 내림차순 정렬 |
| 파일 읽기/저장 | `pd.read_csv('a.csv')`, `df.to_csv('b.csv')` | CSV 파일 |

### **4-7. turtle — 거북이 그래픽**

화면의 거북이에게 "앞으로 가", "돌아"라고 명령해서 그림을 그리는 모듈이다. 반복문 연습에 좋다.

| **환경** | **불러오기** |
| --- | --- |
| 구글 코랩 (강의) | `!pip install ColabTurtle` 후 `import ColabTurtle.Turtle as tur` → `tur.initializeTurtle()` |
| 내 컴퓨터 (표준 모듈) | `import turtle as tur` → 별도 창이 열림 |

| **함수** | **동작** |
| --- | --- |
| `forward(거리)` / `backward(거리)` | 앞으로 / 뒤로 이동 |
| `right(각도)` / `left(각도)` | 오른쪽 / 왼쪽으로 회전 |
| `color('blue')` | 펜 색 |
| `pensize(10)` | 펜 굵기 |
| `penup()` / `pendown()` | 펜 들기(선 안 그림) / 내리기 |
| `clear()` | 그림 지우기 |

**강의 예제: 반복문으로 도형 그리기**

```python
# 사각형: 4번 반복, 90도씩 회전
for iin range(4):
    tur.forward(100)
    tur.right(90)

# 별: 5번 반복, 144도씩 회전
for iin range(5):
    tur.right(144)
    tur.forward(100)

# 육각형: 6번 반복, 60도씩 회전
for iin range(6):
    tur.forward(150)
    tur.right(60)
```

> 💡 **정다각형 공식**: n각형은 `range(n)`번 반복하면서 **`360 / n`도**씩 회전한다. 별(오각별)은 한 번에 꼭짓점 두 칸씩 건너뛰므로 `720 / 5 = 144`도다.

### **5-1. datetime — 날짜와 시간**

```python
import datetimeas dt
```

| **클래스** | **의미** | **예** |
| --- | --- | --- |
| `dt.date(년, 월, 일)` | 날짜 | `dt.date(2026, 10, 26)` |
| `dt.datetime(년, 월, 일, 시, 분, 초)` | 날짜 + 시간 | `dt.datetime(2026, 10, 26, 14, 30, 5)` |
| `dt.timedelta(days=, hours=, ...)` | 시간 **간격** | `dt.timedelta(days=100)` |
| `dt.datetime.now()` / `dt.date.today()` | 지금 / 오늘 |  |

```python
d= dt.date(2026, 10, 26)
print(d.year, d.month, d.day)          # 2026 10 26
print(d.weekday())                     # 0  ← 월요일=0 ... 일요일=6

# 날짜 계산
print(dt.date(2026, 12, 25) - d)                # 60 days, 0:00:00
print((dt.date(2026, 12, 25) - d).days)         # 60  ← 크리스마스까지 D-60
print(d+ dt.timedelta(days=100))               # 2027-02-03  ← 100일 뒤

# 날짜 → 문자열 (strftime), 문자열 → 날짜 (strptime)
x= dt.datetime(2026, 10, 26, 14, 30, 5)
print(x.strftime("%Y-%m-%d %H:%M:%S"))          # 2026-10-26 14:30:05
print(x.strftime("%Y년 %m월%d일"))             # 2026년 10월 26일
print(dt.datetime.strptime("2026-03-01 09:00", "%Y-%m-%d %H:%M"))   # 2026-03-01 09:00:00
```

| **서식** | **의미** | **예** |
| --- | --- | --- |
| `%Y` / `%y` | 연도 4자리 / 2자리 | `2026` / `26` |
| `%m` | 월 (01~12) | `10` |
| `%d` | 일 (01~31) | `26` |
| `%H` / `%I` | 시 (24시간 / 12시간) | `14` / `02` |
| `%M` | **분** | `30` |
| `%S` | 초 | `05` |
| `%p` | AM / PM | `PM` |
| `%A` / `%a` | 요일 영어 전체 / 약자 | `Monday` / `Mon` |

> ⚠️ **`%m`은 월(month), `%M`은 분(minute)** 이다. 대소문자를 바꿔 쓰면 엉뚱한 값이 나온다.
> 
> 
> 💡 윤년도 자동으로 계산된다. `dt.date(2024, 2, 28) + dt.timedelta(days=1)` → `2024-02-29`, `dt.date(2025, 2, 28) + dt.timedelta(days=1)` → `2025-03-01`

### **5-3. collections — 편리한 자료구조**

```python
from collectionsimport Counter, defaultdict, deque, namedtuple
```

**`Counter` — 개수 세기**

```python
cnt= Counter("banana")
print(cnt)                  # Counter({'a': 3, 'n': 2, 'b': 1})
print(cnt['a'], cnt['z'])   # 3 0   ← 없는 키도 에러 없이 0
print(cnt.most_common(1))   # [('a', 3)]  ← 가장 많은 것
```

**`defaultdict` — 기본값이 있는 딕셔너리**

```python
dd= defaultdict(int)       # 없는 키는 int() = 0으로 시작
for win "a b a c a".split():
    dd[w] += 1              # KeyError 없이 바로 += 가능
print(dict(dd))             # {'a': 3, 'b': 1, 'c': 1}

groups= defaultdict(list)  # 없는 키는 빈 리스트로 시작
groups['x'].append(1)
print(dict(groups))         # {'x': [1]}
```

**`deque` — 양쪽 끝에서 빠르게 넣고 빼기 (큐)**

```python
dq= deque([1, 2, 3])
dq.appendleft(0)            # 왼쪽에 추가
dq.append(4)                # 오른쪽에 추가
print(dq)                   # deque([0, 1, 2, 3, 4])
print(dq.popleft())         # 0  ← 왼쪽에서 꺼냄
print(dq.pop())             # 4  ← 오른쪽에서 꺼냄
print(dq)                   # deque([1, 2, 3])
```

리스트의 `pop(0)`은 뒤의 원소를 전부 한 칸씩 당겨야 해서 느리지만, `deque.popleft()`는 바로 꺼낸다.

**`namedtuple` — 이름으로 접근하는 튜플**

```python
Point= namedtuple('Point', ['x', 'y'])
p= Point(3, 4)
print(p)                    # Point(x=3, y=4)
print(p.x, p[1])            # 3 4  ← 이름으로도, 인덱스로도 접근
```

### **5-4. itertools — 순열·조합 ⭐**

```python
from itertoolsimport permutations, combinations, product, combinations_with_replacement
```

| **함수** | **의미** | **순서** | **중복** | **`'ABC'`에서 2개** | **개수** |
| --- | --- | --- | --- | --- | --- |
| `permutations(x, r)` | **순열** | 따짐 | X | AB AC BA BC CA CB | 3P2 = 6 |
| `combinations(x, r)` | **조합** | 안 따짐 | X | AB AC BC | 3C2 = 3 |
| `product(x, repeat=r)` | 중복 순열 | 따짐 | O | (`'AB'`, 2) → AA AB BA BB | 2² = 4 |
| `combinations_with_replacement(x, r)` | 중복 조합 | 안 따짐 | O | (`'AB'`, 2) → AA AB BB | 3 |

```python
print(list(permutations('ABC', 2)))
# [('A', 'B'), ('A', 'C'), ('B', 'A'), ('B', 'C'), ('C', 'A'), ('C', 'B')]

print(list(combinations('ABC', 2)))
# [('A', 'B'), ('A', 'C'), ('B', 'C')]

print(len(list(permutations(range(5), 3))))   # 60  (5P3)
print(len(list(combinations(range(5), 3))))   # 10  (5C3)
```

> 💡 결과는 `permutations` 객체라 `list()`로 감싸야 내용이 보인다. 개수만 필요하면 `math.perm(5, 3)`, `math.comb(5, 3)`이 더 간단하다.

### **5-7. json — 데이터 주고받기**

**JSON**은 웹에서 데이터를 주고받을 때 쓰는 **문자열 형식**이다. 생김새가 파이썬 딕셔너리와 거의 같다.

| **함수** | **방향** |
| --- | --- |
| `json.dumps(객체)` | 파이썬 객체 → JSON **문자열** (dump **s**tring) |
| `json.loads(문자열)` | JSON 문자열 → 파이썬 객체 (load **s**tring) |
| `json.dump(객체, 파일)` / `json.load(파일)` | 파일에 쓰기 / 파일에서 읽기 |

```python
import json

obj= {'name': '김파이', 'pass': True, 'memo': None}

print(json.dumps(obj))
# {"name": "김파이", "pass": true, "memo": null}
print(json.dumps(obj, ensure_ascii=False))
# {"name": "김파이", "pass": true, "memo": null}

back= json.loads('{"name": "kim", "ok": true, "x": null}')
print(back, type(back))
# {'name': 'kim', 'ok': True, 'x': None} <class 'dict'>
```

| **파이썬** | **JSON** |
| --- | --- |
| `dict` | 객체 `{}` |
| `list`, `tuple` | 배열 `[]` |
| `True` / `False` | `true` / `false` (소문자) |
| `None` | `null` |
| 작은따옴표 `'a'` | **큰따옴표만** `"a"` |

> ⚠️ 한글이 `김...`처럼 깨져 보이면 `ensure_ascii=False`를 추가한다. 또 JSON의 키는 **문자열만** 가능해서, `{1: 'a'}`를 변환했다 되돌리면 `{'1': 'a'}`로 키가 문자열이 된다.
> 

### **5-8. re — 정규 표현식**

문자열에서 **패턴**을 찾는다. (정규식 기호는 HTML/CSS 정리의 회원가입 폼 부분 참고)

| **함수** | **동작** | **예시** | **결과** |
| --- | --- | --- | --- |
| `re.findall(패턴, 문자열)` | 일치하는 것 **전부** 리스트로 | `re.findall(r'\d+', '010-1234-5678')` | `['010', '1234', '5678']` |
| `re.search(패턴, 문자열)` | **어디든** 처음 일치하는 것 하나 | `re.search(r'\d+', 'abc123').group()` | `'123'` |
| `re.match(패턴, 문자열)` | **맨 앞부터** 일치하는지 | `re.match(r'\d+', 'abc123')` | `None` |
| `re.sub(패턴, 바꿀것, 문자열)` | 찾아서 바꾸기 | `re.sub(r'\s+', ' ', 'a   b    c')` | `'a b c'` |
| `re.split(패턴, 문자열)` | 패턴 기준으로 자르기 | `re.split(r'[,;]', 'a,b;c')` | `['a', 'b', 'c']` |

```python
import re

# 전화번호 형식 검사
print(bool(re.match(r'010-\d{4}-\d{4}$', '010-1234-5678')))   # True

# 이메일에서 아이디와 도메인 뽑기 (괄호 = 그룹)
m= re.search(r'(\w+)@(\w+)\.com', 'mail: kim@test.com')
print(m.group(), m.group(1), m.group(2))    # kim@test.com kim test
```

> ⚠️ `match`와 `search`의 차이가 시험에 나온다. `match`는 문자열 **시작**에서만 찾으므로 `'abc123'`에서 숫자를 못 찾고 `None`을 반환한다. 패턴 앞의 `r`은 `\`를 그대로 쓰기 위한 **raw 문자열** 표시다.

### **5-9. copy — 얕은 복사와 깊은 복사**

```python
import copy

a= [[1, 2], [3]]
b= copy.copy(a)        # 얕은 복사: 안쪽 리스트는 공유
c= copy.deepcopy(a)    # 깊은 복사: 안쪽까지 전부 새로
a[0].append(9)
print(b)    # [[1, 2, 9], [3]]  ← 같이 바뀜
print(c)    # [[1, 2], [3]]     ← 그대로
```

### **5-11. decimal — 정확한 소수 계산**

```python
from decimalimport Decimal

print(0.1 + 0.2)                          # 0.30000000000000004
print(Decimal('0.1') + Decimal('0.2'))    # 0.3
```

컴퓨터는 실수를 2진수로 저장해서 `0.1`을 정확히 표현하지 못한다. 돈 계산처럼 오차가 있으면 안 될 때 `Decimal`을 쓴다.

> ⚠️ `Decimal(0.1)`처럼 **실수를 넣으면** 이미 오차가 생긴 값이 들어간다. 반드시 **문자열** `Decimal('0.1')`로 만든다.
