## **1. 컬렉션 4종 한눈에 비교**

**컬렉션(Collection)** 은 여러 값을 하나의 이름으로 묶어 관리하는 자료형이다.

| **구분** | **리스트 `list`** | **튜플 `tuple`** | **세트 `set`** | **딕셔너리 `dict`** |
| --- | --- | --- | --- | --- |
| 기호 | `[1, 2, 3]` | `(1, 2, 3)` | `{1, 2, 3}` | `{'a': 1, 'b': 2}` |
| 생성 함수 | `list()` | `tuple()` | `set()` | `dict()` |
| 순서(인덱스) | O | O | **X** | 입력 순서 유지 (인덱스 X, **키**로 접근) |
| 변경(mutable) | O | **X** | O | O |
| 중복 | O | O | **X** | 키 **X** / 값 O |
| 접근 방법 | `a[0]` | `t[0]` | 불가 (반복문, `in`) | `d['a']` |
| 주 용도 | 순서 있는 데이터 목록 | 바뀌면 안 되는 데이터 | 중복 제거, 집합 연산 | 이름표(키)로 값 찾기 |

> ⚠️ **강의 자료 보충:** 강의 자료에는 "**딕셔너리는 순서가 없다**"고 되어 있지만, **Python 3.7부터 딕셔너리는 넣은 순서를 유지한다.** 다만 `d[0]` 같은 **숫자 인덱스로 접근할 수는 없고** 키로만 접근하므로, "인덱스가 없다"는 의미로 이해하면 된다.
> 

### **어떤 컬렉션을 쓸까?**

```
여러 값을 묶고 싶다
  │
  ├─ 이름표(키)로 값을 찾아야 한다 ──────────▶ 딕셔너리
  │
  ├─ 중복 제거 / 교집합·합집합이 필요하다 ───▶ 세트
  │
  ├─ 값이 바뀌면 안 된다 ────────────────────▶ 튜플
  │
  └─ 그 외 (순서 있는 목록, 추가·삭제) ─────▶ 리스트
```

## **2. 만들기: 생성 방법과 함정**

```python
# 리스트: 자료형이 달라도 한 리스트에 담을 수 있음
a= []
a= ['python', 'java', 1, 10, [9, 55]]

# 튜플: 소괄호 생략 가능
t= (10, 20, 30)
t= 10, 20, 30          # 이것도 튜플

# 세트: 중복이 자동으로 제거됨
s= {1, 2, 3, 3}         # {1, 2, 3}
s= set([1, 2, 2, 5])    # {1, 2, 5}

# 딕셔너리
d= {'학번': 1000, '이름': '파이썬'}
d= dict(학번=1000, 이름='파이썬')
d= dict([('a', 1), ('b', 2)])
d= dict(zip(['a', 'b'], [1, 2]))   # {'a': 1, 'b': 2}
```

### **⚠️ 시험 단골 함정 3가지**

| **코드** | **결과** | **이유** |
| --- | --- | --- |
| `x = {}` | **딕셔너리** | 빈 중괄호는 dict. 빈 세트는 `set()` |
| `x = (1)` | **정수 1** | 괄호는 그냥 계산 순서 괄호. 원소 하나짜리 튜플은 `(1,)` |
| `x = (1,)` | 튜플 | **쉼표**가 튜플을 만든다 |

```
print(type({}))      # <class 'dict'>
print(type(set()))   # <class 'set'>
print(type((1)))     # <class 'int'>
print(type((1,)))    # <class 'tuple'>
```

### **➕ 세트의 원소, 딕셔너리의 키가 될 수 있는 것**

세트의 원소와 딕셔너리의 키는 **변경 불가능한(hashable) 값**만 가능하다.

| **가능** | **불가능** |
| --- | --- |
| `int`, `float`, `str`, `bool`, `tuple` | `list`, `set`, `dict` |

```
{(1, 2): 'ok'}     # ⭕ 튜플은 키 가능
{[1, 2]: 'no'}     # ❌ TypeError: cannot use 'list' as a dict key (unhashable type: 'list')
{[1, 2]}           # ❌ TypeError: cannot use 'list' as a set element
```

## **3. 내장함수 총정리 (표)**

> **"반환값" 열을 꼭 보자.** 리스트를 직접 바꾸는 메소드는 대부분 **`None`을 반환**한다. 시험에서 가장 많이 틀리는 부분이다.
> 

### **3-1. 모든 컬렉션에 쓰는 공통 함수 (내장 함수)**

| **함수** | **설명** | **예시** | **결과** |
| --- | --- | --- | --- |
| `len(x)` | 원소 개수 | `len([1, [2, 3]])` | `2` |
| `sum(x)` | 합계 (숫자만) | `sum((1, 2, 3))` | `6` |
| `max(x)` / `min(x)` | 최댓값 / 최솟값 | `max(['apple', 'cherry'])` | `'cherry'` |
| `sorted(x)` | 정렬된 **새 리스트** 반환 (원본 유지) | `sorted({3, 1, 2})` | `[1, 2, 3]` |
| `sorted(x, reverse=True)` | 내림차순 | `sorted([1, 3, 2], reverse=True)` | `[3, 2, 1]` |
| `sorted(x, key=함수)` | 기준을 정해 정렬 | `sorted(['bb', 'a'], key=len)` | `['a', 'bb']` |
| `reversed(x)` | 뒤집은 순서로 꺼내는 반복자 | `list(reversed((1, 2, 3)))` | `[3, 2, 1]` |
| `enumerate(x, start=0)` | (번호, 값) 쌍 | `list(enumerate('ab', 1))` | `[(1, 'a'), (2, 'b')]` |
| `zip(a, b)` | 같은 위치끼리 묶기 (**짧은 쪽에 맞춤**) | `list(zip([1, 2, 3], 'ab'))` | `[(1, 'a'), (2, 'b')]` |
| `any(x)` | 하나라도 참이면 True | `any([0, 1])` | `True` |
| `all(x)` | 모두 참이면 True (**빈 컬렉션은 True**) | `all([])` | `True` |
| `값 in x` | 포함 여부 | `3 in (1, 2, 3)` | `True` |
| `값 not in x` | 미포함 여부 | `3 not in [1, 2]` | `True` |
| `del x[i]` | 인덱스/키로 삭제 (list, dict) | `del a[0]` | — |
| `list()` `tuple()` `set()` `dict()` | 형 변환 | `list('abc')` | `['a', 'b', 'c']` |
| `type(x)` | 자료형 확인 | `type((1,))` | `<class 'tuple'>` |

> 💡 **딕셔너리에 공통 함수를 쓰면 키를 기준으로 동작한다.** `len(d)`는 키 개수, `max(d)`는 가장 큰 키, `sum({1:'a', 2:'b'})`는 키의 합 `3`, `list(d)`는 키 목록, `for k in d`도 키를 꺼낸다.
> 

### **3-2. 시퀀스 연산자 (리스트, 튜플, 문자열 공통)**

| **연산** | **설명** | **예시** | **결과** |
| --- | --- | --- | --- |
| `a[i]` | 인덱싱 (음수는 뒤에서부터) | `[10, 20, 30][-1]` | `30` |
| `a[start:end]` | 슬라이싱 (**end는 포함 안 함**) | `[10, 20, 30, 40][1:3]` | `[20, 30]` |
| `a[start:end:step]` | 간격 슬라이싱 | `[10, 20, 30, 40, 50][::2]` | `[10, 30, 50]` |
| `a[::-1]` | 뒤집기 | `(1, 2, 3)[::-1]` | `(3, 2, 1)` |
| `a + b` | 이어 붙이기 (새 객체) | `(1, 2) + (3,)` | `(1, 2, 3)` |
| `a * n` | n번 반복 | `[0] * 3` | `[0, 0, 0]` |

### **3-3. 리스트 메소드**

| **메소드** | **설명** | **반환값** | **예시 (`a = [3, 1, 2]`로 시작)** | **결과 `a`** |
| --- | --- | --- | --- | --- |
| `append(x)` | 끝에 x **하나** 추가 | `None` | `a.append([4, 5])` | `[3, 1, 2, [4, 5]]` |
| `extend(iter)` | 끝에 여러 개를 **풀어서** 추가 | `None` | `a.extend([4, 5])` | `[3, 1, 2, 4, 5]` |
| `insert(i, x)` | i번 위치에 x 삽입 | `None` | `a.insert(1, 9)` | `[3, 9, 1, 2]` |
| `remove(x)` | **값** x를 찾아 **첫 번째 하나만** 삭제 (없으면 `ValueError`) | `None` | `a.remove(1)` | `[3, 2]` |
| `pop()` | **마지막** 원소를 꺼내 삭제 | 꺼낸 값 | `a.pop()` → `2` | `[3, 1]` |
| `pop(i)` | **인덱스** i의 원소를 꺼내 삭제 | 꺼낸 값 | `a.pop(0)` → `3` | `[1, 2]` |
| `clear()` | 전부 삭제 | `None` | `a.clear()` | `[]` |
| `index(x)` | 값 x의 **첫** 위치 (없으면 `ValueError`) | 인덱스 | `a.index(2)` → `2` | 변화 없음 |
| `count(x)` | 값 x의 개수 | 개수 | `a.count(1)` → `1` | 변화 없음 |
| `sort()` | **원본을** 오름차순 정렬 | `None` | `a.sort()` | `[1, 2, 3]` |
| `sort(reverse=True)` | 원본을 내림차순 정렬 | `None` | `a.sort(reverse=True)` | `[3, 2, 1]` |
| `reverse()` | 원본 순서를 **뒤집기** (정렬 아님) | `None` | `a.reverse()` | `[2, 1, 3]` |
| `copy()` | 얕은 복사본 | 새 리스트 | `b = a.copy()` | 변화 없음 |

> ⚠️ **강의 자료 보충: 값으로 지우는 것은 `remove()`**, **위치로 지우는 것은 `pop()`과 `del`** 이다.
> 

### **3-4. 튜플 메소드**

튜플은 변경할 수 없으므로 메소드가 **두 개뿐**이다.

| **메소드** | **설명** | **예시 (`t = (1, 2, 2, 3, 2)`)** | **결과** |
| --- | --- | --- | --- |
| `count(x)` | 값 x의 개수 | `t.count(2)` | `3` |
| `index(x)` | 값 x의 첫 위치 | `t.index(2)` | `1` |

`append`, `remove`, `sort` 등은 없다. 정렬된 결과가 필요하면 `sorted(t)`(리스트로 반환됨)를 쓴다.

### **3-5. 세트 메소드와 집합 연산**

| **메소드** | **연산자** | **설명** | **예시 (`A = {1, 2, 3, 4}`, `B = {3, 4, 5}`)** | **결과** |
| --- | --- | --- | --- | --- |
| `add(x)` |  | 원소 하나 추가 | `A.add(9)` | `A`에 9 추가 |
| `update(iter)` | `|=` | 여러 원소 추가 | `A.update([7, 8])` | `A`에 7, 8 추가 |
| `remove(x)` |  | x 삭제 (**없으면 `KeyError`**) | `A.remove(99)` | `KeyError` |
| `discard(x)` |  | x 삭제 (**없어도 에러 없음**) | `A.discard(99)` | 변화 없음 |
| `pop()` |  | **임의의** 원소 하나를 꺼내 삭제 | `A.pop()` | 어떤 값일지 보장 안 됨 |
| `clear()` |  | 전부 삭제 | `A.clear()` | `set()` |
| `copy()` |  | 얕은 복사 | `A.copy()` |  |
| `union(B)` | `A | B` | 합집합 | `A | B` | `{1, 2, 3, 4, 5}` |
| `intersection(B)` | `A & B` | 교집합 | `A & B` | `{3, 4}` |
| `difference(B)` | `A - B` | 차집합 (A에만 있는 것) | `A - B` | `{1, 2}` |
| `symmetric_difference(B)` | `A ^ B` | 대칭차집합 (한쪽에만 있는 것) | `A ^ B` | `{1, 2, 5}` |
| `issubset(B)` | `A <= B` | A가 B의 부분집합인가 | `{1, 2} <= {1, 2, 3}` | `True` |
| `issuperset(B)` | `A >= B` | A가 B를 포함하는가 | `A >= {1, 2}` | `True` |
| `isdisjoint(B)` |  | 공통 원소가 없는가 | `{1, 2}.isdisjoint({3})` | `True` |
| `intersection_update(B)` | `&=` | A를 교집합 결과로 **바꿈** | `A &= B` | `A = {3, 4}` |
| `difference_update(B)` | `-=` | A를 차집합 결과로 **바꿈** | `A -= B` | `A = {1, 2}` |

> Mermaid가 렌더링되지 않는 환경용 텍스트 버전
> 

```
        A                       B
  ┌───────────┬───────────┬───────────┐
  │  A에만     │   공통     │    B에만   │
  │  1, 2     │   3, 4    │    5      │
  └───────────┴───────────┴───────────┘

  A | B  (합집합)       = 1, 2, 3, 4, 5   ← 전부
  A & B  (교집합)       = 3, 4            ← 가운데
  A - B  (차집합)       = 1, 2            ← 왼쪽
  B - A  (차집합)       = 5               ← 오른쪽
  A ^ B  (대칭차집합)   = 1, 2, 5         ← 가운데 빼고 전부
```

> 💡 세트는 순서가 없어서 출력 순서가 실행 환경마다 다를 수 있다. (작은 정수는 정렬된 것처럼 보이는 경우가 많지만 보장되지 않는다.) 정렬된 결과가 필요하면 `sorted(세트)`를 쓴다.
> 

### **3-6. 딕셔너리 메소드**

| **메소드** | **설명** | **반환값** | **예시 (`d = {'a': 1, 'b': 2}`)** | **결과** |
| --- | --- | --- | --- | --- |
| `d[key]` | 값 조회 (**없으면 `KeyError`**) | 값 | `d['z']` | `KeyError` |
| `d[key] = v` | 추가 (키가 있으면 **수정**) | — | `d['c'] = 3` | `{'a': 1, 'b': 2, 'c': 3}` |
| `get(key)` | 값 조회 (**없으면 `None`**) | 값 / `None` | `d.get('z')` | `None` |
| `get(key, 기본값)` | 없으면 기본값 반환 | 값 / 기본값 | `d.get('z', 0)` | `0` |
| `keys()` | 키 목록 | `dict_keys` | `d.keys()` | `dict_keys(['a', 'b'])` |
| `values()` | 값 목록 | `dict_values` | `d.values()` | `dict_values([1, 2])` |
| `items()` | (키, 값) 튜플 목록 | `dict_items` | `d.items()` | `dict_items([('a', 1), ('b', 2)])` |
| `update(d2)` | 병합. **겹치는 키는 d2의 값으로 덮어씀** | `None` | `d.update({'b': 20, 'c': 3})` | `{'a': 1, 'b': 20, 'c': 3}` |
| `pop(key)` | 키를 꺼내 삭제 (없으면 `KeyError`) | 값 | `d.pop('a')` → `1` | `{'b': 2}` |
| `pop(key, 기본값)` | 없으면 기본값 반환 (에러 없음) | 값 / 기본값 | `d.pop('z', '없음')` | `'없음'` |
| `popitem()` | **마지막에 넣은** (키, 값) 꺼내 삭제 | 튜플 | `d.popitem()` | `('b', 2)` |
| `setdefault(key, v)` | 키가 없으면 v로 추가, 있으면 기존 값 반환 | 값 | `d.setdefault('c', 0)` | `'c': 0` 추가 |
| `clear()` | 전부 삭제 | `None` | `d.clear()` | `{}` |
| `copy()` | 얕은 복사 | 새 dict | `d.copy()` |  |
| `dict.fromkeys(keys, v)` | 키 목록으로 새 딕셔너리 | 새 dict | `dict.fromkeys(['a', 'b'], 0)` | `{'a': 0, 'b': 0}` |
| `del d[key]` | 키 삭제 (없으면 `KeyError`) | — | `del d['a']` | `{'b': 2}` |
| `key in d` | **키**가 있는지 확인 | bool | `'a' in d` | `True` |

> ⚠️ **강의 자료 보충:** `in`은 **키만** 검사한다. 값을 검사하려면 `in d.values()`를 써야 한다.
> 
> 
> ```python
> d= {'a': 1, 'b': 2}
> print('a' in d)           # True   ← 키 검사
> print(1 in d)             # False  ← 1은 키가 아님
> print(1 in d.values())    # True   ← 값 검사
> print(('a', 1) in d.items())  # True
> ```
> 

### **3-7. 삭제 방법 비교 (가장 헷갈리는 부분)**

| **방법** | **대상** | **기준** | **반환값** | **없을 때** |
| --- | --- | --- | --- | --- |
| `list.remove(x)` | 리스트 | **값** (첫 번째 하나) | `None` | `ValueError` |
| `list.pop(i)` | 리스트 | **인덱스** (기본: 마지막) | 꺼낸 값 | `IndexError` |
| `del list[i]` | 리스트 | **인덱스** / 슬라이스 | — | `IndexError` |
| `set.remove(x)` | 세트 | 값 | `None` | `KeyError` |
| `set.discard(x)` | 세트 | 값 | `None` | **에러 없음** |
| `dict.pop(k)` | 딕셔너리 | 키 | 꺼낸 값 | `KeyError` (기본값 주면 에러 없음) |
| `del dict[k]` | 딕셔너리 | 키 | — | `KeyError` |
| `clear()` | list, set, dict | 전체 | `None` | — |

## **4. 실습 예제 7가지**

### **예제 1. 성적 관리 (딕셔너리 + 리스트)**

```python
scores = {'kim': [90, 80], 'lee': [70, 90], 'park': [95, 85]}

# 학생별 평균 (딕셔너리 컴프리헨션)
avg = {name: sum(points) / len(points) for name, points in scores.items()}
print(avg)

# 평균 높은 순으로 정렬
ranking = sorted(avg.items(), key=lambda x: x[1], reverse=True)
for i, (name, score) in enumerate(ranking, start=1):
    print(f"{i}등 {name}: {score}점")
```

```python
{'kim': 85.0, 'lee': 80.0, 'park': 90.0}
1등 park: 90.0점
2등 kim: 85.0점
3등 lee: 80.0점
```

- `items()`는 `(키, 값)` 튜플을 주므로 `for name, s in ...`처럼 바로 풀어 쓸 수 있다.
- `key=lambda x: x[1]`은 "튜플의 1번 원소(점수)를 기준으로 정렬하라"는 뜻이다.
- `lambda`와 `key=`
    
    강의에서는 다루지 않았지만, `sorted()`, `max()`, `min()`의 `key=`와 함께 **아주 자주** 쓰이고 시험 코드에도 종종 등장하는 문법. 
    
    #### **1. lambda란? — 이름 없는 한 줄짜리 함수**
    
    ```
    lambda 매개변수: 반환할 식
    ```
    
    12강에서 배운 `def` 함수를 **한 줄로 줄여 쓴 것**이라고 생각하면 된다.
    
    ```python
    # def로 만든 함수
    def add(a, b):
        return a+ b
    
    # 똑같은 기능의 lambda
    add2= lambda a, b: a+ b
    
    print(add(2, 3))              # 5
    print(add2(2, 3))             # 5
    print((lambda x: x* 2)(5))   # 10  ← 만들자마자 바로 호출
    ```
    
    | **구분** | **`def` 함수** | **`lambda`** |
    | --- | --- | --- |
    | 이름 | 있음 (`add`) | **없음** (익명 함수) |
    | 길이 | 여러 줄 가능 | **식 하나만** |
    | `return` | 직접 씀 | **안 씀** (`:` 뒤의 식 결과가 자동으로 반환됨) |
    | 주 용도 | 재사용하는 일반 함수 | **한 번 쓰고 버리는** 간단한 함수 (`key=`, `map`, `filter`) |
    
    ```
    lambda  x  :  x[1]
      │     │      │
      │     │      └─ 반환할 값 (return 없이 이 식의 결과가 반환됨)
      │     └─ 매개변수 (이름은 자유: x, s, stu, item ...)
      └─ "지금부터 이름 없는 함수를 만든다"
    ```
    
    > 💡 `lambda`의 매개변수 이름은 아무거나 써도 된다. `lambda x: x[1]`, `lambda s: s[1]`, `lambda stu: stu[1]`은 모두 같은 함수다. `x`가 무슨 뜻인지 헷갈리면, 원소가 무엇인지 드러나는 이름을 쓰자.
    > 
    
    #### **2. `key=`는 어떻게 동작할까?**
    
    `sorted(컬렉션, key=함수)`는 **각 원소를 함수에 넣어서 나온 결과값끼리 비교**해서 정렬한다. 원소 자체는 바뀌지 않는다.
    
    ```
     원소              key 함수 lambda x: x[1]       비교용 값
     ('kim', 85)   ─────────────────────────▶     85
     ('lee', 92)   ─────────────────────────▶     92
     ('park', 78)  ─────────────────────────▶     78
                                │ 비교용 값 기준 정렬 (78 → 85 → 92)
                                                    ▼
     결과: [('park', 78), ('kim', 85), ('lee', 92)]   ← 원소는 그대로, 순서만 바뀜
    ```
    
    ```python
    students= [('kim', 85), ('lee', 92), ('park', 78)]
    
    print(sorted(students, key=lambda x: x[1]))   # 점수(1번 원소) 기준 정렬
    print(max(students, key=lambda x: x[1]))      # 점수가 가장 높은 학생
    ```
    
    ```
    [('park', 78), ('kim', 85), ('lee', 92)]
    ('lee', 92)
    ```
    
    `key=` 없이 `sorted(students)`라고 쓰면 튜플의 **첫 번째 원소(이름)** 부터 비교해서 이름순으로 정렬된다.
    
    #### **이미 있는 함수는 lambda 없이 이름만 넘긴다**
    
    | **코드** | **기준** | **결과** |
    | --- | --- | --- |
    | `sorted(['banana', 'kiwi', 'apple'], key=len)` | 길이 | `['kiwi', 'apple', 'banana']` |
    | `sorted([3, -5, 1, -2], key=abs)` | 절댓값 | `[1, -2, 3, -5]` |
    | `sorted(['b', 'A', 'c', 'B'], key=str.lower)` | 대소문자 무시 | `['A', 'b', 'B', 'c']` |
    | `sorted(['b', 'A', 'c', 'B'])` | (기본) 대문자가 먼저 | `['A', 'B', 'b', 'c']` |
    
    > ⚠️ `key=len()`처럼 **괄호를 붙이면 안 된다.** 괄호를 붙이면 그 자리에서 `len()`을 실행해 버려서 `TypeError: len() takes exactly one argument (0 given)`가 난다. `key=`에는 함수를 **실행한 결과가 아니라 함수 자체**를 넘긴다.
    > 
    
    #### **3. 딕셔너리를 값 기준으로 정렬하기 ⭐**
    
    딕셔너리를 그냥 정렬하면 **키** 기준이므로, 값 기준으로 정렬하려면 `items()`와 lambda를 함께 쓴다.
    
    ```python
    fruits= {'banana': 3, 'kiwi': 5, 'apple': 3}
    
    # 1) 값이 큰 순서로 (키, 값) 목록
    print(sorted(fruits.items(), key=lambda x: x[1], reverse=True))
    
    # 2) 값이 큰 순서, 값이 같으면 키의 알파벳 순서
    print(sorted(fruits.items(), key=lambda x: (-x[1], x[0])))
    
    # 3) 값 기준으로 키만 정렬 / 값이 가장 큰 키
    print(sorted(fruits, key=fruits.get))
    print(max(fruits, key=fruits.get))
    ```
    
    ```
    [('kiwi', 5), ('banana', 3), ('apple', 3)]
    [('kiwi', 5), ('apple', 3), ('banana', 3)]
    ['banana', 'apple', 'kiwi']
    kiwi
    ```
    
    - `x`는 `items()`가 주는 `(키, 값)` 튜플이므로 `x[0]`은 키, `x[1]`은 값이다.
    - 2)처럼 **튜플을 반환**하면 첫 번째 기준이 같을 때 두 번째 기준으로 비교한다. 숫자에 를 붙이면 그 기준만 내림차순이 된다.
    - `fruits.get`은 "키를 넣으면 값을 돌려주는 함수"이므로 `lambda k: fruits[k]`와 같은 역할을 한다. (역시 괄호 없이 넘긴다.)
    
    > 💡 1)에서 `banana`와 `apple`은 값이 3으로 같다. 이렇게 비교값이 같은 원소들은 **원래 순서를 그대로 유지**한다(안정 정렬, stable sort). 그래서 딕셔너리에 먼저 들어간 `banana`가 앞에 온다.
    > 
    
    #### **➕ lambda와 자주 같이 쓰는 `map()`, `filter()`**
    
    | **함수** | **역할** | **예시** | **결과** |
    | --- | --- | --- | --- |
    | `map(함수, 컬렉션)` | 모든 원소에 함수를 적용 | `list(map(lambda x: x * 2, [1, 2, 3]))` | `[2, 4, 6]` |
    | `filter(함수, 컬렉션)` | 함수 결과가 참인 원소만 남김 | `list(filter(lambda x: x % 2 == 0, [1, 2, 3, 4]))` | `[2, 4]` |
    - `map()`, `filter()`의 결과는 리스트가 아니라 `map` 객체, `filter` 객체이므로 **`list()`로 감싸야** 내용이 보인다.
    - 같은 결과를 리스트 컴프리헨션으로도 만들 수 있다: `[x * 2 for x in [1, 2, 3]]`, `[x for x in [1, 2, 3, 4] if x % 2 == 0]`
    
    #### **lambda 확인 문제**
    
    ```python
    words= ['Cat', 'apple', 'Banana']
    print(sorted(words))
    print(sorted(words, key=str.lower))
    print(sorted(words, key=lambda w: w[-1]))
    
    nums= [15, 3, 22, 8]
    print(sorted(nums, key=lambda n: n% 10))
    
    f= lambda x: xif x> 0 else 0
    print(f(-3), f(4))
    ```
    
    > 정답 보기
    > 
    
    ```python
    ['Banana', 'Cat', 'apple']
    ['apple', 'Banana', 'Cat']
    ['Banana', 'apple', 'Cat']
    [22, 3, 15, 8]
    0 4
    ```
    
    - 기본 정렬은 **대문자가 소문자보다 앞**이라 `'apple'`이 맨 뒤로 간다.
    - `w[-1]`은 마지막 글자: `'a'`(Banana) < `'e'`(apple) < `'t'`(Cat)
    - `n % 10`은 일의 자리: 22→2, 3→3, 15→5, 8→8
    - lambda 안에서도 `값1 if 조건 else 값2` 형태의 조건 표현식은 쓸 수 있다. (`if` 문 블록은 쓸 수 없음)

### **예제 3. 중복 제거 (세트 vs 순서 유지)**

```python
langs= ['파이썬', '자바', '파이썬', 'C', '자바']
```

### **예제 5. 학생 명단 (튜플의 리스트)**

```python
students= [('kim', 25, 'A'), ('lee', 22, 'B'), ('park', 23, 'A')]

# 나이순 정렬
print(sorted(students, key=lambda s: s[1]))

print([namefor name, age, cls in studentsif cls == 'A'])
```

### **예제 7. 키와 값 뒤집기 / 두 리스트로 딕셔너리 만들기**

### **시험 직전 체크리스트**

| **#** | **핵심** | **한 줄 정리** |
| --- | --- | --- |
| 1 | 빈 세트 | `{}`는 딕셔너리, 빈 세트는 `set()` |
| 2 | 원소 1개 튜플 | `(1,)` — 쉼표 필수 |
| 3 | 튜플 변경 | 칸은 못 바꾸지만, 칸 안의 리스트 내용은 바뀜 |
| 4 | `None` 반환 | `sort`, `append`, `extend`, `insert`, `remove`, `reverse`, `clear`, `update` |
| 5 | 값을 반환하는 삭제 | `list.pop()`, `dict.pop()`, `dict.popitem()`, `set.pop()` |
| 6 | `remove` vs `pop` | `remove(값)`, `pop(인덱스)` |
| 7 | `sort()` vs `sorted()` | 원본 변경 + `None` / 새 리스트 반환 + 원본 유지 |
| 8 | 슬라이싱 | 끝 번호 미포함, 범위 초과해도 에러 없음 |
| 9 | 복사 | `b = a`는 같은 객체, `a.copy()`는 얕은 복사, `deepcopy`는 깊은 복사 |
| 10 | 세트 삭제 | 없는 값: `remove` → `KeyError`, `discard` → 에러 없음 |
| 11 | 딕셔너리 조회 | 없는 키: `d[k]` → `KeyError`, `get(k)` → `None` |
| 12 | 딕셔너리 `in`, `for`, `len`, `max` | 모두 **키** 기준 |
| 13 | 중복 키 | 에러 없이 마지막 값으로 덮어씀 |
| 14 | 키·원소 자격 | 변경 불가능한 값만 (list ✕, tuple ⭕) |
| 15 | 딕셔너리 순서 | 3.7부터 입력 순서 유지 (단, 숫자 인덱스 접근은 불가) |
