## 1.  2강 - 변수와 값

#### 1. 변수 (variable)

- 정의: 어떤 값을 저장하기 위한 메모리 공간
- 규칙:
    - 이름만 봐도 알 수 있게 할 것 (너무 함축적이지 않게)
    - 영문대소문자, _, 숫자 사용 / 숫자로 시작 불가
    - 미리 선언하지 않아도 되지만 코드가 길면 미리 선언 권장
    - 예약어 (`for`, `while`, `if`, `elif`, `else`, `class`, `try`, `axcept` 등) 사용 피하기
- 더 다양한 예약어 종류
    | **True / False** | 참/거짓을 표현하기 위한 자료형 부울(Boolean, Bool)에는 True, False 딱 2가지의 값만 존재한다. 파이썬에서 숫자 0은 False, 0을 제외한 모든 정수는 True를 의미한다. |
    | **None** | 값이 없거나 알 수 없음(absence of a value or a null value)을 의미한다. NoneType이라는 자료형에 존재한다. |
    | **and** | 둘 다 True면 True, 둘 중 하나라도 False가 있으면 False. 둘 다 False면 False |
    | **as** | 모듈 이름 다음에 as 가 올 경우, as 다음의 이름을 임포트한 모듈에 직접 연결한다. |
    | **assert** | 프로그램에 디버깅 어서션(debugging assertion)을 삽입하는 편리한 방법이다. |
    | **break** | 반복문(while 문 또는 for 문)에서 빠져나올때 쓰는 예약어. 조건이 참이면 반복문 중단. |
    | **class** | 클래스를 정의할 때 쓰는 예약어 |
    | **continue** | 조건이 참이면 반복문이 계속 |
    | **def** | 함수를 정의할 때 쓰는 예약어 |
    | **del** | 인덱스를 사용하여 항목을 삭제하는 예약어 |
    | **elif** | else if의 줄임말. 조건이 거짓이면 elif문이 실행된다. 조건을 여러개 걸고 싶을 때 사용하는 예약어 |
    | **else** | if문에서 조건이 거짓이면 else로 넘어가 다음 명령이 실행된다. elif는 여러 개 쓸 수 있으나 else는 하나만 쓸 수 있다. |
    | **except** | 오류에 대한 예외 처리 관련 예약어. |
    | **finally** | 오류에 대한 예외 처리 관련 예약어 |
    | **for** | 반복문 예약어 |
    | **from** | 현재 네임스페이스(namespace)로 특정 모듈 중 일부(specific attributes or functions)를 가져온다 |
    | **global** | 변수 범위(scope) 관련 예약어 |
    | **if** | 조건문 예약어 |
    | **import** | 현재 네임스페이스(namespace)로 특정 모듈 전체를 가져오는 예약어 |
    | **in** | 시퀀스 자료형(리스트, 튜플, 문자열 등) 안에 어떤 값이 들어있는지 여부를 확인하는 예약어 |
    | **is** | 두 값의 참조(레퍼런스, 포인터)를 비교하는 연산자. ==는 값을 비교하는 연산자로 is와 다르다. |
    | **lambda** | 익명 함수를 만드는 연산자. |
    | **nonlocal** | 변수 범위(scope) 관련 예약어 |
    | **not** | True, False의 반대값을 출력하는 예약어 (예: >>> not False 의 결과값은 True) |
    | **or** | 둘 다 True면 True. 둘 중 하나라도 True가 있으면 True.둘 다 False면 False |
    | **pass** | 어떤 조건문 밑에 pass를 쓰면 그 조건을 실행하지 않고 다음 명령을 실행한다 |
    | **raise** | 파이썬에서 기본적으로 뜨는 오류 외에 프로그래머가 오류 상황을 직접 정의하여 예외를 발생시켜야 할 때 사용하는 예약어 |
    | **return** | 함수 안에서 사용되어 값을 반환하고 함수문을 빠져나오는 예약어 |
    | **try** | 오류에 대한 예외 처리 관련 예약어 |
    | **while** | 반복문 예약어. |
    | **with** | 예외문 관련, _enter_ 및 _exit_와 함께 쓰이는 예약어 |
    | **yield** | 함수 안에서 사용되어 return과 비슷한 역할을 하는 예약어. 그러나 yield는 gernerator를 반환한다는 점에서 차이가 있다. |

## 2.  3강 - 연산자

#### 1. 산술 연산자

- +, -, *, /, //(몫), %(나머지), **(거듭제곱)
- 결과는 보통 숫자 / 문자열에도 쓰임.

#### 2. 대입 연산자

- = 으로 표시. 새 값 대입 시 기존값 대체. 오른쪽 → 왼쪽으로 진행
- num1 = num2 = num3 = 100 (모두 100)
- 왼쪽에는 변수만, 오른쪽에는 상수/변수 등
- 복합 연산자: 산술 연산자와 대입 연산자를 합친 것. (+=, -=, *=, /=, //=, %=, **=)

```python
>>> a = 2
>>> a *= 3  # a = a * 3과 같음
>>> print(a)
6
```

- 대입연산자는 결과물을 내는 것이 아니라 ‘저장’하는 개념.

#### 3. 비교 연산자

- ==, !=, >, <, >=, ≤
- 결과는 True/False 의 Bool 형태.

#### 4. 논리 연산자

- & (and), | (or) , not
- not의 결과는 항상 bool형태. &, | 는 양쪽 값 중 하나를 그대로 돌려준다.

```python
# & (and) : 양쪽 조건이 모두 참일 때만 True 반환
>>> True and True
True
>>> True and False
False
>>> False and True
False
>>> False and False
False

# | (or) : 양쪽 조건 중 하나라도 참이면 True 반환
>>> True or True
True
>>> True or False
True
>>> False or True
True
>>> False or False
False

# not : 참과 거짓을 반대로 바꾼다.
>>> not True
False
>>> not False
True
>>> not 1
False
>>> not 0
True
```

#### 5. 연산자 우선순위

- 수학과 동일. 먼저 계산하려면 괄호() 사용.

## 4.  5강 - 문자열 추출

#### 1. 인덱싱 (indexing)

- 첫 문자 인덱스 0, 오른쪽으로 갈 수록 증가
- 마지막 문자 인덱스 -1, 왼 쪽으로 갈수록 감소

## 5. 6강 - 함수, 내장 함수

#### 1. 함수란?

- 특정 기능을 하는 코드 묶음.
- 입력 → 출력. 반복 호출 가능
- 내장 함수 / 사용자 정의 함수

#### 2. print() 함수

- ‘ , ’로 나열 시 한 칸 띄어 출력
- 서식 지정 : `%d`(정수), `%f(`실수), `%c`(문자 1개), `%s`(문자열)
    - 동적 지정 예 : `print(”%d %d %f” % (100, 200, 0.1))`

#### 3. 문자열 함수

: 문자열(객체)은 여러가지 기능을 가진 함수를 내장하고 있다.

| 문자열 함수 분류 | 내장 함수 | 설명 |
| --- | --- | --- |
|  1. 대소문자 변환 | `upper()` | 모든 소문자 → 대문자 |
|  | `lower()` | 모든 대문자 → 소문자 |
|  | `title()` | 각 단어의 제일 앞 글자만 대문자로 변환 |
| 2. 문자열 찾기  | `count()` | 찾을 문자열의 개수 |
|  | `find()` | 찾고자 하는 문자열이 몇 번째 인덱스인지. |
|  | `index()` | `find()`와 같은 기능 |
|  | `startswith()` | 찾을 문자열로 시작하면 True |
|  | `endswith()` | 찾을 문자열로 끝나면 True |
| 3. 공백 제거/변경  | `replace()` | 문자열 내의 특정 문자를 새 문자열로 치환 |
|  | `strip()` | 앞뒤 공백만 제거 |
| 4. 분리/결합 | `split()` | 문자열을 특정문자로 분리하여 리스트로 반환 |
|  | `join()` | 문자열을 합쳐줌 |
| 5. 동적 지정  | `format()` | 특정 값을 변수화하여 동적으로 문자열 생성* |
| 6. 기타 자주 쓰는 함수  | `sum()` | 전체의 합을 계산 |
|  | `range()`  | 정수를 입력하면 0~지정된 범위의 값 반환 |
|  | `len()`  | 아이템의 개수(글자수)를 세주는 기능 |
|  | `int()` ,`float()` , `str()` | 각 타입으로 변환 |

동적 지정 예)

```python
temperature = 25
prob = 70
text = '오늘 기온: {}도, 강수 확률: {}%'.format(temperature, prob)
```

- 문자열 포매팅 (String Formatting)
    - 문자열 안의 특정한 값을 바꿔야 할 경우가 있을 때 가능하게 해주는 것. 문자열 안에 어떤 값을 삽입하는 한 방법이다.
    1. 숫자 바로 대입
    
    ```python
    print("I have %d pineapples." %3)
    
    # 결과물: I have 3 pineapples.
    ```
    
    1. 문자열 바로 대입
    
    ```python
    print("I have %s pineapples." % "five")
    
    # 결과물 : I have five pineapples.
    ```
    
    1. 숫자 값을 나타내는 변수로 대입
    
    ```python
    number = 3
    print("I have %d pineapples" % number)
    
    # 결과물 : I have 3 pineapples.
    ```
    
    1. 2개 이상의 값 넣기
    
    ```python
    number = 5
    day = "eight"
    print("I ate %d pineapples. so I was sick for %s days." % (number, day))
    
    # 결과물 : I ate 5 pineapples. so I was sick for eight days.
    ```
    
    ✓ 기호 %와 포매팅 연산자 %d를 같이 쓸 때는 기호를 ‘%%’로 표시한다.
    예시) `"Error is %d%%." % 98`

## 6. 7강 - 함수 심화(1)

#### 1. 함수가 필요한 이유

: 복붙 반복 방지, 코드 정리, 에러/오류 디버깅 용이

#### 2. 함수 생성 방법

```python
def 함수명(파라미터1, ..., 파라미터n):
		구현 코드
		return 반환값
```

- 파라미터(인자): 없거나 여러개 가능. 함수도 전달 가능. 기본값 지정 가능 (예: x=100으로 값 지정).
- 구현 코드(body): 기능 수행 부분
- `return` : 결과 반환 + 함수 종료
    - `return`만 있거나 `return`이 없으면 None 반환
    - 여러 값 반환 가능 → 호출 시에 복수의 변수 설정 필요.
- 함수명: 기능을 알 수 있게 작성할 것.

#### 3. 함수의 호출

- `함수명(파라미터1, … , 파라미터n)` → 정의된 순서대로 파라미터를 전달해야한다.

## 7. 8강 - 함수 심화(2)

#### 1. 변수의 범위

1. 전역 변수(global variable): 상단에 선언되어 코드 끝까지 유지되는 변수
2. 지역 변수(local variable): 함수 안에서 선언되어 함수 안에서만 사용된다.

```python
a = 20 #전역변수

def func1():
		a = 10 #지역변수
		print("func1()에서 a의 값: %d" % a)
		
def func2():
		print("func2()에서 a의 값: %d" % a)
		
func1() # 10, 지역변수 
func2() # 20, 전역변수 
```

#### 2. 파라미터

1. 가변 길이 인자: 파라미터 수가 고정적이지 않다.
2. 키워드 파라미터: 이름 = 값 으로 전달. 이름 생략 시 순서대로 전달.
예) `add(x-10, y=50, z=3)` 혹은 `add(10, 50, 3)`
3. 디폴트 파라미터: 기본값 지정
- 디폴트 파라미터를 둘 때는 일반 파라미터 뒤에 둔다.
예) `def test(a, b=1, c=2)`
