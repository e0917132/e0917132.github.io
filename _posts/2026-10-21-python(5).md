## **1. 클래스(class)란?**

**클래스**는 현실 세계의 사물을 **속성(attribute)**과 **동작(method)**으로 표현한 **데이터 타입**이다. 쉽게 말해 **설계도**에 해당한다.

| **구분** | **의미** | **다른 이름** | **자동차 예시** |
| --- | --- | --- | --- |
| 속성 | 가지고 있는 **데이터** (변수) | 필드(field), 멤버 변수 | 색상, 속도 |
| 동작 | 할 수 있는 **기능** (함수) | 메소드(method), 멤버 함수 | 속도 올리기, 속도 내리기 |

```
# 클래스 선언
class Car:
    # 자동차의 속성 (변수)
    color= ""
    speed= 0

    # 자동차의 동작 (함수)
    def upSpeed(self, value):
        pass      # pass: 아직 구현하지 않았다는 표시 (빈 블록 에러 방지)

    def downSpeed(self, value):
        pass
```

### **💡 사실 우리는 이미 클래스를 쓰고 있었다**

파이썬의 `str`, `list`, `dict` 같은 자료형은 **모두 클래스로 구현되어 있다.**

```
a= [1, 2, 3, 4]
a.append(5)        # list 클래스에 들어 있는 append 메소드를 호출
print(a)           # [1, 2, 3, 4, 5]
print(type(a))     # <class 'list'>  ← 'class'라고 출력된다
```

`type()`의 결과가 `<class '...'>` 형태로 출력되는 것도 이 때문이다.

### **캡슐화(encapsulation)**

리스트 안에는 **데이터**(1, 2, 3, 4)와 그 데이터를 다루는 **기능**(append, sort, pop …)이 함께 들어 있다. 이처럼 **데이터와 기능을 하나로 묶는 것**을 **캡슐화**라고 한다.

> ➕ **클래스 이름 짓는 관례**: 클래스 이름은 단어의 첫 글자를 대문자로 쓴다(`Car`, `MyCar`, `StudentInfo`). 변수나 함수 이름은 소문자로 써서(`my_car`, `up_speed`) 클래스와 구분한다. 문법상 필수는 아니지만 대부분의 코드가 이 관례를 따른다.

## **2. 객체(object)란?**

**객체**는 클래스(설계도)를 바탕으로 **실제로 만들어진 것**이다. **인스턴스(instance)**라고도 부른다.

| **클래스** | **객체(인스턴스)** |
| --- | --- |
| 붕어빵 **틀** | 틀로 찍어낸 **붕어빵** |
| 설계도 | 설계도대로 만든 실제 자동차 |
| 1개 | **여러 개** 만들 수 있음 |

틀 하나로 붕어빵을 여러 개 찍어 내듯이, 클래스 하나로 객체를 여러 개 만들 수 있다. 또한 각 붕어빵에 팥을 넣든 슈크림을 넣든 **서로 영향을 주지 않는다.**

### **객체지향 프로그래밍(OOP)**

파이썬은 **객체지향 프로그래밍(OOP, Object Oriented Programming)** 언어이다.

- 데이터를 **객체**로 다루며, 객체 간의 상호작용으로 프로그램이 동작한다.
- 장점: 코드 **재사용성**이 높고, 코드를 직관적으로 분석할 수 있으며, 개발과 디버깅 속도가 향상된다.

---

## **3. 객체 생성하기**

객체를 만들려면 **클래스가 먼저 선언되어 있어야** 한다. 생성 방법은 함수 호출과 같은 형태인 `클래스이름()`이다.

```
myCar= Car()           # 객체 생성
myCar.color= "빨강"     # 객체.속성 = 값
myCar.speed= 0

print(myCar.color)      # 빨강
```

- `객체.속성`처럼 **점(.)**을 사용해 객체 안의 속성에 접근한다.
- 그러나 이 방식은 객체를 만들 때마다 속성 값을 **한 줄씩 직접 입력해야** 하므로 번거롭고, 입력을 빠뜨리기도 쉽다.
- 이 문제를 해결하는 것이 바로 **생성자**이다.

---

## **4. 생성자 `__init__`**

**생성자**는 **객체가 만들어질 때 자동으로 호출되는 특별한 메소드**로, 속성의 **초기값**을 설정하는 데 사용한다.

- 이름은 반드시 `__init__` (init 앞뒤로 **언더바 2개씩**)
- `init`은 **initialize(초기화)**의 약자
- 직접 호출하지 않아도 `Car()`를 실행하는 순간 **자동으로** 실행됨
- 장점: 코드가 간결해지고, 초기값 입력을 빠뜨리는 실수를 방지함

### **4-1. 기본 생성자 (self 외에 매개변수 없음)**

```
class Car:
    def __init__(self):
        self.color= "빨강"
        self.speed= 0

myCar= Car()                       # 생성되는 순간 __init__ 자동 실행
print(myCar.color, myCar.speed)     # 빨강 0
```

#### **생성자가 없을 때 vs 있을 때**

```
# ❌ 생성자 없음: 만들 때마다 직접 값 입력
myCar= Car()
myCar.color= "빨강"
myCar.speed= 0

# ⭕ 생성자 있음: 한 줄로 해결
myCar= Car()
```

### **4-2. 매개변수가 있는 생성자**

기본 생성자로는 모든 자동차가 **빨강, 0**으로만 만들어진다는 한계가 있다. 생성자에 매개변수를 추가하면 **객체마다 다른 값**으로 초기화할 수 있다.

```
class Car:
    def __init__(self, color, speed):
        self.color= color# 전달받은 값을 객체의 속성에 저장
        self.speed= speed

myCar= Car("빨강", 10)
myCar2= Car("파랑", 20)

print("자동차 1의 색상은%s이며, 현재 속도는%dkm/h" % (myCar.color, myCar.speed))
print("자동차 2의 색상은%s이며, 현재 속도는%dkm/h" % (myCar2.color, myCar2.speed))
```

```
자동차 1의 색상은 빨강이며, 현재 속도는 10km/h
자동차 2의 색상은 파랑이며, 현재 속도는 20km/h
```

> ➕ **`self.color = color`의 의미**
> 
> - 오른쪽 `color`: 생성자로 **전달받은 값** (매개변수이며, 함수가 끝나면 사라짐)
> - 왼쪽 `self.color`: **객체에 저장되는 속성** (객체가 존재하는 동안 유지됨)
> 
> 두 변수는 이름이 같지만 **서로 다른 변수**이다. 08강에서 다룬 **지역 변수**와 같은 개념이다.
> 

> ➕ 생성자에도 08강의 **디폴트 파라미터**를 사용할 수 있다.
> 
> 
> ```
> class Car:
>     def __init__(self, color="흰색", speed=0):
>         self.color= color
>         self.speed= speed
> 
> c1= Car()            # 흰색 0
> c2= Car("검정")       # 검정 0
> ```
>

## **5. ➕ `self`의 정체**

강의 자료에는 "`self`는 클래스 자기 자신을 가리킨다"고 되어 있으나, 더 정확히 말하면 `self`는 **메소드를 호출한 객체 자기 자신**을 가리킨다.

```
myCar= Car("빨강", 10)
myCar2= Car("파랑", 20)
```

- `myCar`를 만들 때의 `self` → **myCar**
- `myCar2`를 만들 때의 `self` → **myCar2**

따라서 같은 코드 `self.color = color`가 실행되더라도 값은 각 객체에 **따로** 저장된다.

### **파이썬이 내부적으로 처리하는 일**

```
myCar.upSpeed(30)
# 파이썬 내부에서는 다음과 같이 바꾸어 실행한다 
Car.upSpeed(myCar, 30)
```

`myCar.upSpeed(30)`이라고 작성하면, 파이썬은 **점(.) 앞의 객체(myCar)를 첫 번째 인자 `self`로 자동 전달**한다. 그러므로

- **정의할 때**는 `def upSpeed(self, value):`처럼 `self`를 **반드시 적고**
- **호출할 때**는 `myCar.upSpeed(30)`처럼 `self` 자리를 **비워 둔다.**

> ⚠️ **강의 자료 보충: "self 생략 가능"에 대하여** 강의 자료에는 "메소드 안에서 속성에 접근할 필요가 없다면 self 생략 가능"이라고 되어 있으나, **일반 메소드에서 self를 생략하면 객체로 호출할 때 에러가 발생한다.** 속성을 사용하지 않더라도 **메소드의 첫 번째 매개변수로 `self`를 항상 적는다**고 기억하는 것이 안전하다. (self 없이 사용하는 `@staticmethod`라는 문법이 별도로 존재)
> 
> 
> ```
> class Test:
>     def hello():          # self 없음
>         print("안녕")
> 
> t= Test()
> t.hello()   # TypeError: Test.hello() takes 0 positional arguments but 1 was given
> ```
> 
> 파이썬이 `t`를 자동으로 전달했지만, 이를 받을 자리(self)가 없어서 발생하는 에러이다.
> 

> 💡 `self`는 관례적으로 쓰는 이름일 뿐 키워드는 아니다. 다른 이름을 써도 동작하지만, **모두가 `self`를 사용하므로 바꾸지 않는 것이 좋다.**
>

## **6. 메소드(method)**

**메소드**는 클래스 안에 정의된 함수(**멤버 함수**)이며, **`객체.메소드명()`** 형태로 호출한다. 주로 **해당 객체의 속성을 계산하거나 변경하는 역할**을 한다.

```
class Car:
    def __init__(self, color, speed):
        self.color= color
        self.speed= speed

    def upSpeed(self, value):
        self.speed+= value# 자기 자신(self)의 speed를 증가

    def downSpeed(self, value):
        self.speed-= value

myCar= Car("빨강", 10)
myCar2= Car("파랑", 20)

myCar.upSpeed(30)       # myCar만 속도 증가
myCar2.downSpeed(5)     # myCar2만 속도 감소

print(myCar.speed)      # 40
print(myCar2.speed)     # 15
```

- `myCar.upSpeed(30)`은 **myCar의 speed만** 변경하며, myCar2에는 영향을 주지 않는다. (붕어빵은 서로 독립적이다.)

### **➕ 값을 반환하는 메소드**

07강에서 다룬 `return`도 그대로 사용할 수 있다.

```
class Car:
    def __init__(self, color, speed):
        self.color= color
        self.speed= speed

    def getInfo(self):
        return "{} 자동차,{}km/h".format(self.color, self.speed)

myCar= Car("빨강", 10)
print(myCar.getInfo())  # 빨강 자동차, 10km/h
```

### **함수 vs 메소드**

| **구분** | **함수** | **메소드** |
| --- | --- | --- |
| 위치 | 클래스 **밖** | 클래스 **안** |
| 호출 | `함수명()` | `객체.메소드명()` |
| 첫 매개변수 | 자유 | **`self`** |
| 예시 | `len(a)`, `print()` | `a.append(5)`, `s.upper()` |

## **7. ➕ 클래스 변수 vs 인스턴스 변수**

강의 자료의 첫 예제에서는 `color = ""`가 **클래스 바로 아래**에 선언되어 있고, 생성자 예제에서는 `self.color`가 **`__init__` 안**에 선언되어 있다. 두 변수는 종류가 다르다.

| **구분** | **클래스 변수** | **인스턴스 변수** |
| --- | --- | --- |
| 선언 위치 | 클래스 바로 아래 | 메소드 안에서 `self.변수` |
| 소속 | **클래스 전체가 공유** | **객체마다 따로 존재** |
| 접근 | `클래스명.변수`, `객체.변수` | `객체.변수` |

```
class Car:
    wheels= 4                  # 클래스 변수: 모든 자동차가 공유

    def __init__(self, color):
        self.color= color# 인스턴스 변수: 자동차마다 다름

a= Car("빨강")
b= Car("파랑")
print(a.wheels, b.wheels)       # 4 4       ← 공유
print(a.color, b.color)         # 빨강 파랑  ← 각자

Car.wheels= 6                  # 클래스 변수를 변경하면
print(a.wheels, b.wheels)       # 6 6       ← 모든 객체에 반영
```

> 💡 **정리**: 모든 객체가 같은 값을 가져야 하면 **클래스 변수**를, 객체마다 값이 달라야 하면 **`__init__` 안의 `self.변수`**를 사용한다. 처음에는 **"속성은 `__init__` 안에서 `self.`로 만든다"**고 기억해 두면 실수를 줄일 수 있다.

## **8. ➕ 자주 발생하는 에러**

| **에러 상황** | **원인** | **해결** |
| --- | --- | --- |
| `TypeError: ... missing 2 required positional arguments: 'color' and 'speed'` | 매개변수가 있는 생성자인데 `Car()`처럼 값을 전달하지 않음 | `Car("빨강", 10)`처럼 값 전달 (또는 디폴트 값 지정) |
| `TypeError: ... takes 1 positional argument but 2 were given` | 메소드 정의에서 `self`를 누락함 | `def upSpeed(self, value):`처럼 self 추가 |
| `NameError: name 'speed' is not defined`
또는 `UnboundLocalError: cannot access local variable 'speed' ...` | 메소드 안에서 `self.speed` 대신 `speed`라고 씀 (읽기만 하면 NameError, `speed += value`처럼 변경하려 하면 UnboundLocalError) | 속성에 접근할 때는 반드시 `self.`를 붙임 |
| `AttributeError: 'Car' object has no attribute 'upSeed'` | 메소드 이름 오타 | 이름 확인 (대소문자도 구분함) |
| `__init__`이 실행되지 않음 | `_init_`(언더바 1개)나 `__int__`로 잘못 씀 | 앞뒤 언더바 **2개씩**, `init` 철자 확인 |

## **9. 한눈에 요약**

### **클래스 사용 3단계**

| **단계** | **작업** | **형식** | **예** |
| --- | --- | --- | --- |
| 1단계 | 클래스 선언 | `class 클래스이름:`
　속성, 메소드 선언 | `class Car:`
　`def upSpeed(self, value): ...` |
| 2단계 | 객체(인스턴스) 생성 | `객체 = 클래스이름()` | `myCar = Car("빨강", 10)` |
| 3단계 | 속성·메소드 사용 | `객체.속성 = 값`
`객체.메소드()` | `myCar.color = "파랑"`
`myCar.upSpeed(30)` |

### **핵심 용어**

| **용어** | **한 줄 설명** |
| --- | --- |
| 클래스 | 설계도 (붕어빵 틀) |
| 객체 = 인스턴스 | 클래스로 만든 실체 (붕어빵) |
| 속성 = 필드 = 멤버 변수 | 객체가 가진 데이터 |
| 메소드 = 멤버 함수 | 객체가 가진 기능 |
| 생성자 `__init__` | 객체 생성 시 자동 실행, 초기값 설정 |
| `self` | 메소드를 호출한 **객체 자기 자신** |
| 캡슐화 | 데이터와 기능을 하나로 묶는 것 |
